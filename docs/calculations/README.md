# CM Lab calculations

These guides document the implementation shipped in 3.3 RC3. Saved game facts, converted values, modelling assumptions and user actions are distinguished; none of these models is certified as the game engine.

- [LabLogic](LabLogic.md): formula, conversion, full position weights and familiarity map.
- [TonTon](TonTon.md): TT2 role groups, robust CA comparisons and Hidden Freak ranking.
- [Coaching](Coaching.md): joint assignment objective and workload assumptions.
- [Best XI](BestXI.md): unique lineup optimisation, national squads and substitutes.
- [Training](Training.md): eight schedules, need/capacity scoring and exact implementation.
- [Find the next](FindNext.md): style/strength similarity and discovery caps.
- [Recruitment](Recruitment.md): comparable-player limits and opportunity signals.
- [Transfer / Move On](MoveOn.md): role-relative squad gaps, PA headroom and age-aware triage.
- [Nation and regens](NationAndRegens.md): eligibility, slot reuse, first-seen and contract months.

Worked examples demonstrate arithmetic, not invented game players. We welcome alternative weights and evidence through [GitHub Issues](https://github.com/mike-appguy/CMLab/issues).

[Table layout controls](TableLayouts.md) describe presentation preferences and keyboard resizing.
